# Artwork slots

Add your finished images here, then replace the matching placeholder block in the main README with a relative Markdown image link. No broken image links or generated artwork are included.

| File | Suggested size | What to show |
| --- | --- | --- |
| `banner.png` | 1600 × 500 | Project name and your main VR artwork |
| `gameplay.png` | 1600 × 900 | A clean in-game headset view |
| `controls.png` | 1600 × 1000 | Quest controls with readable labels |
| `computer.png` | 1600 × 900 | The controller laser operating a computer |

Example for the main README:

```markdown
![Scam With Your Friends in VR](docs/images/banner.png)
```

Use your own artwork or game captures you have permission to share. Do not include account identifiers, invite codes or private chat in screenshots.
